# 听课笔记16：终身学习（Lifelong Learning）

## 一、什么是终身学习（LLL）

- AI 可以不断学习新的任务，越来越聪明，掌握各种技能，超越所有人类（continues learning）
- 真实世界里的应用：用标注出的资料训练出模型后上线，再用上线后的资料来更新模型
- 当前学会一个任务再学另一个任务（大概是不同领域但相近的资料，比如辨识不同颜色的数字）——如果学了第一个直接学第二个，机器可能会遗忘第一个任务
- 但如果直接把两个任务的资料都混合在一起训练，就能在两个任务上都取得比较好的结果（多个任务也有类似现象）

## 二、Catastrophic Forgetting（灾难性遗忘）

- **Multi-task training 可以解决**——但问题是每训练一种新的技能，都要把前面所有学过技能的资料都找出来和新的混在一起重新学习（可以视为 LLL 的 upper bound）
- 假如让每一个模型都分别学一种技能（不同任务不同模型）——一是技能很多的话要很多模型，二是不同的资料这样也做不到互通有无
- 与 transfer learning 不同的是：**LLL 需要考虑所有任务的实现情况，而不是只评估新任务的情况**

## 三、评估

### R(i,j) 评估表格

- 评估要用一个特殊的表格：R(i,j) = after training task i, performance on task j
- 示例表格（3 个任务，N 个任务同理，每个格子是 R(i,j)）：

| R(i,j) | 测任务1 | 测任务2 | 测任务3 |
| --- | --- | --- | --- |
| **训任务1** | R(1,1) | R(1,2) | R(1,3) |
| **训任务2** | R(2,1) | R(2,2) | R(2,3) |
| **训任务3** | R(3,1) | R(3,2) | R(3,3) |

- 怎么看：
  - **对角线** R(i,i)：学完任务 i 后任务 i 本身的表现（一般较高）
  - **下三角**（i > j，学后面的任务后测前面的任务）：R(i,j) 明显低于 R(j,j) → 学新任务后旧任务表现退化 = **灾难性遗忘的信号**
  - **上三角**（i < j，还没学任务 j 时测它）：迁移的起点/baseline

### 三个评估指标（T = 总任务数）

- **Average Accuracy（平均准确率）**：$ACC = \frac{1}{T}\sum_{i=1}^{T} R_{T,i}$——学完所有任务后，所有任务的平均表现（矩阵最后一行的平均）
- **Backward Transfer（BWT，后向迁移/遗忘度）**：$BWT = \frac{1}{T-1}\sum_{j=1}^{T-1}(R_{T,j} - R_{j,j})$——学完全部任务后 vs 刚学完任务 j 时，任务 j 表现的差值平均；**负值 = 灾难性遗忘**（越负忘得越厉害），≈0 = 没忘
- **Forward Transfer（FWT，前向迁移）**：$FWT = \frac{1}{T-1}\sum_{j=2}^{T}(R_{j-1,j} - \bar{R}_j)$——还没学任务 j（只学了它前面的任务）时对任务 j 的表现，减去随机初始化时的 baseline $\bar{R}_j$；正值 = 前面的任务对新任务有帮助

## 四、解决灾难性遗忘的方法

### 1. Selective Synaptic Plasticity（选择性突触可塑性）——EWC

- 为什么会有灾难性遗忘：每个任务的损失函数 error surface 都不太相同——对一个任务好的参数对另一个不一定
- 但是每一个参数对每个任务的重要程度是不同的：对前一个任务重要的参数就不动，对前一个不是那么重要的就去适应新的任务
- 公式：$L' = L + \lambda \sum_i b_i(\theta_i - \theta_i^*)^2$
  - 各部分：$L$ = 当前（新）任务的损失；$\lambda$ = 正则化强度；$b_i$ = 第 i 个参数对旧任务的重要程度（费雪信息 Fisher information）；$\theta_i$ = 当前参数；$\theta_i^*$ = 学完旧任务后保存的参数值
  - 含义：参数越重要（bᵢ 大），偏离旧值 θᵢ* 的惩罚越重——被"弹性地钉"在旧值附近；不重要的参数可以自由移动去学新任务——这就是"选择性突触可塑性"的数学实现
- 参数选择要点：
  - 如果 bᵢ 太小，就不会被旧任务束缚 → 出现灾难性遗忘
  - 如果 bᵢ 太大，就不会去学习新的任务——一点小的参数更改都会有大的损失
  - 对于不同的参数应该有不同的 bᵢ，因为不同参数重要性不同

### 2. Gradient Episodic Memory（GEM）

- 在 update 参数之前，综合考虑两个任务的参数优化方向
- 问题：需要把过去所有的资料都存下来，违背最初精神

### 3. Additional Neural Resource Allocation（额外神经资源分配）

- **Progressive Neural Network**：每一个任务都新增一组参数，不动前面已经训练好的参数——但这需要额外的空间
- **PackNet**：先准备一个大的网络，让每一个任务都只占用一部分小的参数
- 两者结合：**CPG**（Compacting, Picking and Growing）

### 4. Memory Reply（记忆回放）

- 用 generator 产生前面任务的资料，然后和新任务的资料一起训练，用这种方法克服灾难性遗忘

任务的顺序也是重要的，有些顺序会带来遗忘，有些不会
