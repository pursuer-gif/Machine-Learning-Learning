# 听课笔记13：领域自适应与预训练模型的通用能力

## 一、Domain Adaptation（领域自适应）

- 领域自适应：模型在不同数据集上的迁移表现
- 如果训练资料和测试资料的分布有一定差异，那么表现或许就会不好

### 目标域有少量标注：预训练 + 微调

- 可以先在 source domain 上先预训练，假如 target domain 上有少量的标注资料，再微调模型，让它在目标任务上表现得比较好

### 目标域完全无标注：对抗式域适应（DANN）

- 运用一个 feature extractor 去除掉 source 和 target 不同的部分，保留相同的部分
- 怎么训练 feature extractor：把网络的前几层拿过来，后面的作为 Label Predictor，根据 source domain 来进行损失 L（Label Predictor 是用源域标注训练的，不是"自动标注"目标域——目标是模型在无标注的目标域上直接分类好）
- 这中间还有一个 domain classifier：判断数据是从哪个数据集上来的，这个分类问题也有一个损失函数 Ld——目标是让 Ld 越小越好（分得清），然后 Feature Extractor 就要想办法骗过 Domain Classifier
- 补充（总损失的正确形式）：总损失 = L − λ·Ld
  - Label Predictor：想让 L 小（分类准）
  - Domain Classifier：想让 Ld 小（分得清来源）
  - Feature Extractor：想让 Ld 大（骗过判别器）——所以 Ld 前是负号
- 补充（怎么做更好 = 梯度反转层 GRL，Gradient Reversal Layer）：前向正常通过，反向传播时梯度取反——一个层同时实现"分类要准 + 域判别要骗"，一次反向传播搞定对抗训练
- 补充（为什么有效）：特征里如果含域信息，判别器就能分出来（Ld 小）；为了骗过它，特征里就不能保留"来自哪个域"的信息 → 只剩任务共性特征——这就是"去掉不同部分、保留相同部分"的实现方式

### 更复杂的情况

- 如果 source domain 和 target domain 之间的关系比较复杂？有不同的标签，比如是交集或者包含关系
- 假如不仅是没有标注，而且 target domain 上的数据也很少：**TTT（Test-Time Training，测试时训练）**——Sun et al., ICML 2020：训练时学主任务 + 自监督辅助任务（如旋转预测），测试时用目标域样本先跑自监督任务更新几步，再预测；自监督任务和主任务共享特征提取器，所以"边用边适应"，无标注 + 数据极少也能用
- 如果一无所知呢？→ **Domain Generalization（域泛化）**

## 二、自监督预训练模型的通用能力

### 多语言能力

- 训练资料少，跨语言能力就不太明显；训练资料多，就更明显——模型也同样重要
- 不同语言之间的差异在机器内部的差异是可以数据化的，因此可以完成语言之间的转换

### 跨学科能力

- 比如可以进行 DNA 的分类，但底层是把 DNA 的碱基序列编码成 token 序列输入（DNA 和自然语言都是离散符号序列，模型学的是符号序列的一般规律——本质是序列建模，不是自然语言处理；自然语言只是它学过的数据之一）
- 任务本身没变（还是序列分类/预测），变的只是输入编码——所以跨学科能力来自"编码的适配"，不是任务转换
- 在人类语言上的预训练让模型的各种领域任务都变得更好
- 预训练的模型能更好地被优化，而且模型举一反三的能力会更加好——即使在训练集的表现上是一样的，但预训练过的模型在测试集上的表现更好

### 语音 + 文本的结合

- 语音的预训练模型 HuBERT 可能没法很好地理解语音中的信息（离散化 + 自注意力本来就是 HuBERT 自身的机制：k-means 聚类成伪标签 → 盖住 → Transformer 预测被盖的单元——问题不在缺这两步，而是它学的单元不携带语义），所以做不出纯语音的文章和问答
- pre-trained Speech model → Pre-trained text model：有预训练后就有比较好的效果（语音 → HuBERT 提供声学表示 → 转成文字 → 预训练文本模型补上语义 → 输出答案；两端都预训练过：语音侧声学表示好、文本侧语义现成，只需学中间一小段对接）

### 在人造数据上也能训练出 BERT

- 通过不同的规则产生不同的训练资料，然后让 BERT 具备不同的能力
- 每一个单词都对应一个 token-id，然后输入 id 向量，输出文字结果
- 如果编造出来的 id 是完全随机的，那么训练的结果不太好；但如果 id 是成对出现的（比如前面有一个 5，后面也有个 5 对应——顺序不一定严格，只要有就可以），那么训练效果也不错
- 还有一种方法是 shuffle：先产生一些连续的 token-id，然后再随机打乱，这样的效果也不错
- 模型学会看一个 sequence 比较长的范围，那么对 NLP 的效果可能会比较好
