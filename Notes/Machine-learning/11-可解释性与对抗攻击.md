# 听课笔记11：机器学习可解释性与对抗攻击

## 一、可解释性（Interpretable ML）

### 为什么需要可解释

- 机器能得到正确的答案，**不证明机器很聪明、有智能**
- 银行贷款、医疗诊断这类事情需要足够可以解释——可以说服别人、说服监管机关
- 深度学习的模型本质是一个黑箱，看不到内部的情况

### 可解释的模型选择

- 线性模型容易被解释，但是不够强力
- 在这种情况下，决策树是一个好的选择吗？随机森林？——在森林的情况下，也很难分析出是怎么做出答案的

### 可解释的目标

- 我们大脑的工作原理其实也不清楚，但是我们相信大脑做出的决策——为什么？两者有什么区别或联系？
- **人能接受的解释就是一个好的解释**
- **Local explanation**（局部）：针对局部的、具体问题的解释
- **Global explanation**（全局）：针对全局的判断规则之类的

### 局部解释方法

- **遮挡法**：判断一个区域是否重要 → 把这些区域分别遮住，看哪个区域被遮住时机器的判断出现错误
- **梯度法**：把某个 pixel（向量的某个维度）改变，看损失函数的变化——**δL/δx 就是重要程度，值越大越重要**
- **Salience Map**：机器觉得重要的点（显著图）
- **Noisy Gradient / SmoothGrad**：加入噪声，然后把不同的 Salience Map 平均起来（去噪）
- **Gradient Saturation**：到一定程度，梯度可能没法反映真实情况

### 观察机器是怎么处理输入数据的

- 用人眼观察：可以把数据用 PCA 或 t-SNE 投影到二维图片上看
- 一开始的输入图片和经过了不同隐藏层后的图片是不一样的——从中可以分析机器的思考过程
- **Probing**：训练一个探针，对每一层的输出进行判断
- **Reconstruction**：尝试重建，以语音训练为例——可以"听"神经网络听到的声音

### 全局解释：在机器眼里一只猫是什么样子的

- 生成一张图，让某一个 filter 的特征值最大，然后看图——看每个 filter 希望看到的图是什么样子的
- 找一张图片进去，让输出是你想要的——但很有可能得到一堆噪声的图片
- 这时要在找图的过程中加入一些额外的限制（比如让有内容的点更少一点）——但这就不单纯是机器看到的了吧，里面有一些人的想法了，更接近强行解释
- 运用 generator 生成图片：z → generator → image x → classifier → y

### 用线性模型模仿黑盒子的行为

- 线性模型比较容易分析，但很可能模仿不成功——只能模仿很小一部分功能或区域吧

## 二、NLP 上的对抗攻击

### 和图片攻击的差异

- 图片：加入人眼无法识别的微小扰动，让机器判断错误
- NLP：和图片不太一样——直接在原始输入加扰动太明显；embedding 后的扰动在机器内部，接触不到

### 攻击类型

- **Evasion 规避攻击**：就是加人眼无法识别的微小扰动——因为对抗攻击大部分是这种，所以也就默认了，实际上这只是其中一种
- **Poisoning 投毒攻击**（笔记里听成 limitation）：训练阶段污染训练数据
- **Backdoor 后门攻击**：训练阶段埋后门，遇到触发器才发作
- 攻击要达成的输出可以是有目标的，也可以是没有目标的

### 例子：利用解析错误的攻击

- Dependency parsing
  - 补充：依存句法分析——分析句子中词与词之间的语法关系，输出一棵依存树（谁修饰谁、谁是谁的主语/宾语）
  - 例："我吃苹果" → 我(主语)→吃，苹果(宾语)→吃，根是谓语
  - 比词性标注更进一步：词性标注给词贴标签（名词/动词），依存分析给词之间连线
  - 用途：机器翻译、问答、关系抽取——理解句子结构
  - 在 NLP 对抗攻击中的角色：攻击目标或解释工具（替换一个词可让情感分类/依存结构出错）
- 实际例子：so sad to see hong kong become part of china → 谷歌翻译："很高兴看到香港成为中国的一部分"（wrong parsing 导致语义反转）
- **Universal suffix dropper**：加通用后缀，让部分内容不被翻译（wrong parsing）

### 文本级攻击手段

- **同义词替换**：用语义向量空间中的距离作为替换标准——这样可能会筛选到不是同义词的一些单词
- **Counter-fitted**：在词向量空间中把同义词拉近、反义词拉远
- **用 BERT 替换**：找概率最高的几个词替换——但这样可能比较容易造成语义的改变，需要人工筛选？这时候就有新的方式：
  - **no masking 的 BERT**：不遮住任何一个单词，让它输出要替换部分的词的几率
- **词形变化（inflectional form）**：改动词、名词、形容词的形态，比如说改将来时、过去时，来制造攻击
- **向量空间的微分生成攻击样本**：把损失函数对向量 δe 求微分
  - Tangent line
  - 补充：切线——函数在某点的局部直线近似，斜率 = 导数：$y = f(x_0) + f'(x_0)(x - x_0)$
  - 在对抗攻击里的角色：损失函数是一个"曲面"，梯度（= 切线方向）告诉攻击者"往哪个方向改输入，损失上升最快（模型最容易出错）"——沿梯度方向加扰动就是攻击
  - 和训练的关系：训练用梯度下降（沿最陡方向下坡），攻击沿最陡方向上坡——同一个工具，方向相反
- **插入/挖空**：根据单词插入——把一个地方挖空格给 BERT 插入，或者去掉一个单词
- **文字层面的转换**：swap（交换词序）/ substitution（替换）/ deletion（删除）/ insertion（插入）
