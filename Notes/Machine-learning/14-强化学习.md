# 听课笔记14：强化学习（Reinforcement Learning）

## 一、强化学习概述

- 给机器一个输入的时候，并不清楚最好的答案是什么——机器只会判断输出的好坏
- 机器根据反馈来调整自己的行为

## 二、三步走（RL 基本框架）

### 1. 定义 Actor（神经网络）

- 先找出一个位置的函数（神经网络），然后判断下一步的行动——本质是一个分类问题，输出概率，并依据概率随机采样

### 2. 定义损失函数

- 一轮游戏称之为 **episode**，计算一整轮得到的 total reward，希望这个越大越好
- 流程：环境 → 行为 → 计算 reward → 依次循环
- **难点**：里面有随机性参与，环境和 reward 是黑盒子，没办法直接通过梯度下降来优化

### 3. 调整 Actor

- 在看到一个输入的时候，希望有一个特定的输出，然后根据原来的输出算 cross-entropy，以此来达到控制的目的（像用训练一个网络的行为来控制 actor 的决策；不希望做出某决策也是可以的）
- 也可以对机器的每一个输入、每一个输出都进行期望调整，以正负分数的形式来表示和控制——但怎么确定输入和输出之间的应对关系也是一个难点

## 三、RL 的核心问题

### 全局性

- 如果每一个 actor 都单独调整，就没有考虑全局——每一个行为都不是独立的
- 有时候需要放弃短期的利益来赢得长期的利益

### Reward delay（奖励延迟）

- 有时候不能获得即时反馈
- 一个行为决策有多好，不能只看马上产生的那个后果，还要看后续所有的、连续反应的反馈
- 但如果这一系列影响非常久，产生某个反馈的原因就不全是前面所有行为共有的、贡献相同的——所以 reward 离行为近的权重大，远的权重小、影响小

### 只有最终结果能收获反馈的网络怎么训练

- reward 需要做一个标准化——不然如果所有的 reward 都是正的，哪怕一个行为不好，如果影响够深远，也会有很高的分数，就不能很好地调整行为
- 简单的一种：所有的分数 G 减去一个 baseline（重点是如何选择）

## 四、Policy Gradient（策略梯度）

- 需要随机化先生成一个网络
- 先跑一次 → 根据机器的行为给反馈 → 根据这次收集的资料调整网络 → 之后就要**重新收集资料**（每一次资料只能对当前的网络更新，不然可能起到反效果）——**on-policy learning**
- 还有一种 **off-policy** 策略：让网络通过特定方法利用之前网络的资料——但必须知道两个网络之间的差异，要有针对性地调整（有些经验可以采纳，有些不可以）
- 收集资料的过程中需要有一些随机性（**exploration**）：不然有些情况的 reward 从来都不知道，就不能很好地训练

## 五、Actor-Critic

### Critic 与 value function

- Critic 用来评估行为的好坏
- **value function**：看到 s 预测一个行为的表现，而不用等所有的结果都出来；与 s 和 actor 都有关——这样就有了一笔训练资料

### Temporal-difference approach（时序差分，TD）

- 看到一部分资料，不需要结束就可以进行训练——原理是利用 V(s) 和 V(s+1) 之间的理论上关系来进行训练
- 补充（TD 更新公式）：$V(s_t) \leftarrow V(s_t) + \alpha [r_t + \gamma V(s_{t+1}) - V(s_t)]$
  - 各部分：$V(s_t)$ = 状态价值估计；$\alpha$ = 学习率；$r_t$ = 即时奖励；$\gamma$ = 折扣因子（0~1，越远的影响越小）；$V(s_{t+1})$ = 下一状态价值
  - $r_t + \gamma V(s_{t+1})$ = **TD target**（"看一步"之后更好的估计）；$r_t + \gamma V(s_{t+1}) - V(s_t)$ = **TD error**（时序差分误差，当前估计和"看了一步"的差距）
  - 理论基础：贝尔曼方程 $V(s) = r + \gamma V(s')$——就是 V(s) 和 V(s+1) 之间的理论关系
  - 为什么叫"时序差分"：用相邻时间步的价值**之差**（temporal 时间上的 difference 差分）来更新
  - 和 Monte Carlo 对比：MC 要等整局结束算总回报 $G_t$；TD 只走一步就用 V(s_{t+1}) 更新（bootstrap，用估计更新估计）——不用等结束、方差更小
- 补充（MC = Monte Carlo，蒙特卡洛——TD 的对比方法）：
  - 估计 V(s) 的另一条路线：等整局结束，用实际总回报 $G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots + \gamma^{T-t}r_T$ 更新：$V(s_t) \leftarrow V(s_t) + \alpha[G_t - V(s_t)]$
  - 因为 $G_t$ 是"真的发生"的回报 → 无偏；但每局随机性大、$G_t$ 波动大 → 方差大
  - 名字来源：Monte Carlo = 摩纳哥赌城，表示"靠大量随机采样估计数值"
  - 类比：MC = 考完试看总分（准确但要等）；TD = 每做一题就预估（快但可能偏）

### Advantage Function（优势函数）：判断动作好不好

- 核心思想：判断 $a_t$ 好不好不能只看绝对回报（有的状态本身回报就高），要看**相对平均水平**——实际结果减去期望
- **方法一（MC 形式）**：$A_t = G_t - V(s_t)$
  - $G_t$ = 随机采取 $a_t$ 后的实际结果（有随机性，真实回报）
  - $V(s)$ = 期望（平均水平的回报）
  - $A_t > 0$ → $a_t$ 比平均水平好（正优势）；$A_t < 0$ → 比平均差
- **方法二（TD 形式，不用等结束）**：$A_t = r_t + \gamma V(s_{t+1}) - V(s_t)$
  - $s_t$ 执行 $a_t$ 后到 $s_{t+1}$：即时奖励 + 下一状态期望 − 当前状态期望
  - $> 0$ → $a_t$ 是比较好的行为
  - 注意：这个形式其实就是 **TD error**——不用等整局结束就能算

## 六、Reward 相关的挑战

### Sparse reward（稀疏奖励）

- 假如 reward 大部分都是 0，那就可能没什么办法训练
- 这时候可以想办法提供额外的 reward 去帮助模型学习——拆成几个部分去引导

### Curiosity（好奇心）

- 鼓励机器去探索新的情况——但是新需要是**有意义的"新"**，不能是杂讯一直新

## 七、Reward 难定义怎么办：模仿学习

### 问题

- 有时候连 reward 都很难定义；而且光定义 reward 也是不够的——机器可能根据 reward 学习到一些比较奇怪的东西（reward hacking）

### Behavior Cloning（行为克隆）

- 这个时候就可以用人类的示范来引导机器学习——叫做 demonstration of the expert（专家示范）
- 这样就有点接近监督学习——但可能会完全模仿人类
- 补充（BC 和 IRL 的对比）：BC 直接学"动作"（模仿表象，没见过的场景就懵，上限 ≤ 专家）；IRL 学"为什么这么做"（reward/意图），再训练 actor，可能超越专家——类比：BC 是抄作业，IRL 是学解题思路

### Inverse Reinforcement Learning（逆向强化学习，IRL）

- 通过 expert → inverse reinforcement learning → reward function 逆向学习
- 老师的行为能得到最高的 reward，但是不代表就要全都模仿老师
- 给老师的行为打高分，给 actor 的行为给较低的分数——有点像 GAN 里的 generator 和 discriminator
- 补充（GAIL 机制，GAN 结构）：专家行为 / actor 行为 → Discriminator 猜"这是谁的"（给专家高分、actor 低分）→ actor（相当于 generator）骗过判别器 → 行为越来越像专家；reward = 判别器给 actor 行为的分数
