# 听课笔记12：对抗攻击与防御

## 一、为什么关注对抗攻击

- 对于一个模型来说，光有正确率是不够的——还要能侦测来自人类的恶意攻击，在遭受攻击的情况下还可以正常工作

## 二、攻击示例与目标设定

### 图片攻击示例

- 在图片的每一个向量上都增加一个比较小的信息，人眼看不出来，但会让模型出错

### 无目标攻击 vs 有目标攻击

- 识别的结果是一个多目标答案的概率分布
- **无目标攻击**：希望输出尽可能大地偏离正确输出，并且杂讯图片和原图片相近——损失函数就定义为**负的 y 和 y-hat 的差值**
- **有目标攻击**：不仅要考虑与正确输出差距大，还要考虑和目标答案差距小；还要注意杂讯图片和原图片相近，相近程度用人类的判断能力来确定

### 扰动大小的度量（两种差值）

- **L2**：算向量的长度——所有值绝对值的平方和开根号
- **L∞**：直接取差值向量中最大的那个
- 如果以人眼的判断标准来看，最好应该从 L∞ 来看——因为一张图很可能是局部变化较大

## 三、攻击方法

### 把输入图片看成网络参数的一部分进行训练

- 需要一个初始化的值；对图片向量的每一个维度都进行求微分，进行梯度下降
- 注意这个时候还需要考虑 **constraints（约束）**：不能超过 L∞ 的限制

### FGSM（Fast Gradient Sign Method，快速梯度符号法）

- 只优化一次参数，加上 sign
- 补充公式：$x^{adv} = x + \epsilon \cdot sign(\nabla_x J(\theta, x, y))$
  - $\nabla_x J$ = 损失对输入 x 的梯度（损失上升最快的方向）；sign = 取符号（只留方向 ±1，丢弃大小）；ε = 扰动幅度（很小，人眼不可见）
  - 为什么用 sign 而不是梯度本身：每个像素都均匀扰动 ±ε，幅度完全可控（L∞ 范数 = ε，正好满足上面的 constraint）——每个维度只动一点点，但大量维度叠加 → 骗过模型
  - 为什么"只优化一次"：只算一次梯度、加一次扰动就完成（所以叫 Fast），不像训练那样迭代很多步
  - 方向：训练是梯度下降（损失 ↓），FGSM 是梯度上升（损失 ↑，让预测偏离正确输出）——和"把输入图片当参数训练"是同一思路，只是只走一步

### 方框限制的图示（2D 示意）

```
维度2
  ▲
  │   ┌─────────────┐
  │   │             │
  │   │      ↗      │  ← 一步沿对角方向走到方框边界
  │   │    x ●      │      x = 原始输入
  │   │             │      方框 = L∞ 约束（每个维度只能动 ±ε）
  │   └─────────────┘
  │        -ε     ε
  └──────────────────────► 维度1
```

- 在方框的限制里，只或上、或下、或左、或右，一步直接到方形的边界上
- 方框 = constraint：每个维度允许的扰动范围 ±ε（2D 里是正方形，高维里是超立方体）
- 为什么是一步到边界：sign 把梯度变成 ±1（每个维度都往同一个方向），再乘 ε → 一步从中心走到方框边界
- 注意：梯度的真实方向未必是对角线，sign 把它"掰"成最近的对角方向（损失上升的近似最优方向）
- 如果多进行几次出了边界，就看哪条边或者哪个角落距离那个变化的点最近

## 四、白盒和黑盒攻击

- **白盒**：知道模型参数
- **黑盒（知道训练方法）**：可以训练一个相近的模型，攻击这个白盒，然后就可以攻击目标模型了
- **黑盒（连训练方法都不知道）**：根据输入和输出来直接训练——在无目标攻击上比较容易成功，在有目标的不太容易成功
- **Ensemble attack（集成攻击）**：在一个模型上攻击成功了，在另外的模型上也比较容易成功

## 五、其他攻击类型

- **One pixel attack**：只改一个像素
- **Universal Adversarial Attack（通用对抗扰动）**：一个杂讯就可以让所有的东西都变错误，不用为每一个输入设置一个特定的杂讯
- **语音攻击**：被机器合成的声音也可以被机器识别出来，但加入一些杂讯后，虽然听起来还是像合成的，机器会认为不是
- **文字攻击**：加入攻击杂讯，让机器读文章后回答出错误的问题
- **人脸识别**：可以被一副特制的眼镜攻击
- **自动驾驶**：对路牌标识的图像进行改变进行攻击
- **Adversarial Reprogramming（对抗重编程）**：
  - 补充：用对抗扰动把预训练模型"重新编程"成做完全不同任务的模型，模型参数一个不动
  - 和普通攻击的区别：普通攻击是让模型出错；重编程是让模型"干别的活"（分类模型变计数模型）——不是错，是挪用
  - 经典例子（Elsayed 2018）：ImageNet 分类模型 → 数方块模型——任务小图放进大输入，周围加固定对抗性包装，某类别输出对应方块数量
  - 关键特点：扰动是固定的、全局的（所有输入共用同一个包装）；模型参数完全不变，攻击者只控制输入
  - 安全意义：别人不用碰你的模型，只靠输入包装就能"借用"；也说明大模型容量冗余，可同时容纳多个任务

## 六、训练阶段攻击（后门/投毒）

- 还可以从训练阶段就开始攻击：在训练资料里加入一些有扰动的资料（人眼看不出来）→ 给模型开后门
- 可能只是对单一的特定的输入会出错
- 如果这个模型被大规模应用，一旦后门被利用可能就会造成很大的损失
- **要小心网络上公开的数据集**

## 七、防御

### 被动防御（模型不动）

- 让输入在进入模型前经过一层 filter，让扰动被减弱，但不影响正常输入
- 也许只需要对图片进行一些模糊化就可以达成很好的效果——但注意不能太过头，不然会导致正常的影像识别受到影响

### 主动防御（处理输入）

- 对图片进行压缩，或者让输入的图片用 generator 重新生成一个一模一样的图片，过滤掉攻击信号
- 弱点：一旦被动防御的模糊化处理被攻击者考虑进去（模糊化和产生攻击信号一起训练），就可以突破
- 这个时候也许就需要**随机化**：对图片进行随机处理，防止防御方式被突破

### Proactive Defence（训练时防御）

- 在训练过程中就对模型进行攻击，让模型有抗性
- 也可以说这是一种**资料增强**的方式——让模型更准确，也更不容易被攻击破
- 缺点：可能被新的攻击方法攻破；而且训练过程中对数据的处理会花更多时间，训练成本更高、吃算力
