# 听课笔记17：元学习（Meta Learning）

## 一、元学习概述

- Meta learning 元学习：**学习如何学习**
- 自动学习 hyperparameter、网络框架、初始参数、学习率
- 能根据新的任务自行设计模型
- 核心公式：**Meta learning: find a function F that finds a function f**——学的是"学习算法 F"（输入少量新任务数据 → 输出好模型），不是模型本身

### 损失函数怎么定义

- 怎么定义损失函数？通过学习算法学出来的模型来判断——用测试资料（query）上的表现来判断这个模型
- 也仍然用相应的 ML 损失函数，比如 cross-entropy
- 如果有不同的任务输入不同的模型设计，就把不同的 Loss 平均起来当做 loss
- 与 ML 不同的是：**在训练过程中使用了测试集（query）**——这里的训练是以任务为单位的，每一个任务看成一次完整的训练
- 如果没有办法求微分呢？可以通过 RL 硬训练
- 宗旨：通过不同类型的任务学习

### 关键结构

- 在任务里的训练资料 = support set，测试资料 = query set
- ML 是 **within-task training**；Meta learning 是 **across-task training**（包含了前者的训练以及测试）——也叫 **outer loop**（外层），里面的是 **inner loop**（内层）
- Meta learning 也同样有过拟合问题——有可能只在训练的那几个任务上做得好

### 任务层面的数据划分（和训练集/验证集/测试集对应）

- training tasks（训练任务）/ development tasks（开发任务 = 任务级的验证集）/ testing tasks（测试任务）
- development tasks：训练过程中反复用——调超参数、选学习算法、监控是否过拟合（"只在训练任务上做得好"就是靠它发现的）；不参与学习算法的参数更新
- testing tasks：训练完全结束后才用，最终评估
- 别和 support/query 混：support/query 是"单个任务内部"的划分（现场学/现场测）；development/testing tasks 是"任务之间"的划分（选哪些任务来验证/最终评估）——两个层面

## 二、MAML（Model-Agnostic Meta-Learning）

- MAML 学的是"初始参数 θ*"（好的起点）——训练时用多个有标注的训练任务（每任务内部：support 现场学几步 → query 测表现），外层优化 θ*，让"从 θ* 出发微调几步后的表现"最好
- 新任务来了：用学到的 θ* 初始化 + 几步梯度就快速适应（不是"在测试集上做参数初始化"）
- 和"预训练 + 微调"思想相近（学通用起点），不是自监督；任务用多样的（任务分布），不是相近的
- 备注：类似一种 domain adaptation（但 MAML 学"快速适应机制"，域适应学"分布对齐"）

### 自监督的机制（和 MAML 的区别）

- 自监督机制：变换数据（盖住/旋转/裁剪）→ 被破坏的部分当标签（数据自带，零人工标注）→ 模型学会恢复/预测 → 学到表示；例：BERT 盖住"吃"让模型填、SimCLR 让增强图对相似
- 和 MAML 的区别：
  - 标签来源：MAML 用任务自带标注（人标）；自监督从数据变换里造（无标注）
  - 学什么：MAML 学初始参数 θ*（快速适应能力）；自监督学数据表示
  - 训练单位：MAML 多个有标注任务；自监督无标注数据 + 伪标签
- 麻烦程度对比：
  - 训练循环：自监督单层（一次前向+反向）；MAML 双层循环（inner 每任务跑几步 + outer 更新），梯度要穿过内层（涉及二阶导，常用一阶近似），计算和显存都更重
  - 数据：自监督只要大量无标注数据（便宜）；MAML 需要多个有标注任务（贵）
  - 实现：自监督简单（变换+预测头）；MAML 复杂
  - 为什么值得麻烦：目标不同——自监督解决"标注贵"（用免费数据学表示）；MAML 解决"新任务学得慢"（few-shot 快速适应）
  - 应用现状：自监督大规模广泛使用（BERT、SimCLR）；MAML 主要用于 few-shot 研究（新类别只有 1~5 个样本的场景）

## 三、元学习还能学什么

- **Optimizer 也可以学出来**（学一个优化规则替代梯度下降）
- **Network Architecture Search（NAS）**：网络结构搜索——很多时候需要用 RL 硬做
- **Data augmentation（数据增强）**：增强策略本身可以学（如 AutoAugment）
- **Sample reweighting**：调整不同数据集的权重
- **Learning to compare**：一个网络直接包括学习和分类

## 四、应用：N-way K-shot Classification

- 种类数（N-way）和每个种类的数量（K-shot）
- 经典数据集：Omniglot

## 五、元学习和其他方法的对比

### vs 自监督学习

- 和 MAML 并不是互斥的，可以把两者结合起来——**MAML 的 initialization 可以来自 BERT**
- BERT 到实际应用还需要微调，可能更通用一些；而 MAML 是有针对性的——对目标任务找初始化参数
- 不过 MAML 的运算量大，而且还需要人工标注的数据

### vs 知识蒸馏

- 正确率最高的老师不见得是最好的老师——不一定能教出来最好的学生
- **Learn to teach**：teacher net 的 update 方向不是让准确率更高，而是让 student net 的准确率更高

### vs 领域自适应（Domain Adaptation）

- 如果不知道目标域的资料，怎么把元学习运用到跨领域学习？
- 可以拿一个训练资料充当目标资料域，然后通过元学习让机器学习如何设计一个能够实现跨领域学习的模型；可以让充当目标域的训练资料轮换，之后就正式应用到实际情况
- 当然，还可能遇到训练资料和测试资料差异较大的情况

### 用到终身学习（Life Long Learning）

- 希望能学到设计一种能够规避灾难性遗忘的网络
- Another level：可能 Meta learning 本身存在灾难性遗忘——在一类任务上能设计出来后，一旦开始处理另外的任务框架设计，就可能把前面的一些任务忘记掉
