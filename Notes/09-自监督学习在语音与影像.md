# 听课笔记9：自监督学习在语音和影像上的应用

## 一、总览：文字、语音、影像都能自监督预训练

- **对于文字**：先用未标注的资料训练 BERT，再把 BERT 的输出当成文字情感辨别的输入
- **对于语音**：
  - 先拿未标注的资料训练语音版 BERT，然后把输出当做 Downstream Model 的输入
  - 固定住 BERT，只微调 Downstream Model 就可以达成优化效果
  - SUPERB：语音领域的任务集，类似 GLUE
- **对于影像**：如果资料集足够大，那么标注是多余的，不用标注也能很好地学习

## 二、生成式方法（Generative Approach）

### 语音版 BERT（模型：Mockingjay）

- 和文字类似：把一部分盖起来，让它预测原本的内容
- 要一次 mask 一长排的 feature，不然可能只学到相邻片段的**线性内插**（从邻居平滑推出来，而不是真懂结构）；文字版 BERT 也有类似理念
- 与文字不同：语音 BERT 训练时不止从时间上考虑，还可以遮挡声音信号的某几个维度，让 BERT 去还原

### 语音版 GPT

- GPT 在文字上是预测下一个 token；在语音上直接预测下一个太简单了
- 所以预测接下来某一段时间（>3 步）之后的向量——**任务要够难才能学到东西**

### 图像版

- 给一张图片，把像素拉长成一条，就和声音、文字非常类似

## 三、预测式方法（Predictive Approach）

- 背景：要产生一张完整的原图很困难，怎么简化这个任务？
- **旋转预测**：把图片旋转但不让机器知道，让它判断图片有没有被旋转、旋转了几度
- **Context prediction**：把图切成几个小块，让机器学习第二块在第一块的哪一个方向（一般 8 个方向可选）——这个训练能帮助机器在其他任务上做得更好
- **声音信号**：判断两个语音信号之间有多远的距离
- 注意：小任务的设计**没有固定答案**，需要你自己对机器学习和任务的理解
- **Predict simplified objects**：直接预测声音信号太难 → 先让机器预测聚类之后的结果（好像就是预测一个个数字？比如 3、5、6 代表类的数字？），这样会相对简单一点

## 四、对比学习（Contrastive Learning）

### 核心思想

- 训练时**输出侧不会产生额外的东西**（不做生成，只判相似度）
- 两张图片假如属于同一类别，经过 encoder 产生的向量就越近；反之越远

### SimCLR

- 对图片进行一些处理（放大、旋转、加滤镜），然后和其他图片的变化结果放在一起 → 这样就不用标注了
- random cropping（随机裁剪）是比较有效的增强

### MoCo

- 补充：Momentum Contrast——维护一个大的负样本队列 + momentum encoder（参数缓慢更新的 encoder），保证负样本又多又稳定

### 语音上的对比学习：CPC / Wav2vec

- 结构：encoder + predictor（CPC 用 GRU，Wav2vec 用 CNN），这部分只处理一部分（当前局部窗口）
- 另一部分是 positive/negative 的判断（特征向量相似度）
- 原理（CPC = Contrastive Predictive Coding，对比预测编码）：
  - 思路：直接预测未来的声音帧太难（生成式）→ 改成判别式：不预测具体内容，只判断"哪个候选才是真正的未来"
  - encoder：把语音按时间切成小段，每段编码成一个特征向量 z
  - predictor：聚合过去所有 z，得到上下文向量 c
  - 对比判断：拿 c 和一组候选向量算相似度
    - positive 正样本：未来 t+k 时刻真实的特征 z_{t+k} → 相似度要高
    - negative 负样本：从其他位置/其他语音里随机取的向量 → 相似度要低
  - 损失：InfoNCE——从 N 个候选中选出正确的那 1 个（本质是 N 选 1 的判别）
  - 学到什么：encoder 的特征里包含"对未来有预测价值"的信息（语音内容、说话人特征），下游任务直接拿来用

### VQ-wav2vec 和 Wav2vec2.0（语音 + BERT 的结合）

- 在 VQ-wav2vec 后面加一个 BERT 做填空题？这是用来抗语音干扰吗？
- 补充：VQ-wav2vec 的关键是**离散化（discretize，笔记里听成 discried）**——用 vector quantization 把连续的 encoder 输出映射成 codebook 里的离散 token（类似文字里的"字"），语音才变成可以填空的符号序列
- 补充 VQ 实现：准备一个码本（codebook）= N 个可学习向量（如 8192 个）；每个连续向量 z 找码本里距离最近的代表向量，量化输出 = 该向量，离散符号 = 它的编号（0~8191）——就像聚类，相近的语音片段落到同一个代号
- "编号"≠字：码本编号只是声音片段的聚类代号，没有文字含义；码本本身是训练中学出来的（相当于"语音的字典"）
- 找最近邻（argmin）不可导 → 用 Gumbel-Softmax（软 one-hot 加权所有码本向量）让"选择"可导；辅以 commitment loss 约束 z 贴近选中的码本向量
- Wav2vec2.0：把前面的 encoder 和 BERT 一起训练——encoder 的输出变成连续的向量给 BERT，让它去预测被盖起来的向量
- 不把它当成一般的正常分类问题：语音对应的 token 类别太多了
- 补充（正常流程）：waveform → encoder（CNN）→ 连续向量 → VQ 离散化成 token → BERT 填空
- 补充（Wav2vec2.0 是什么）：语音界的 BERT——三件套：CNN encoder（波形→连续向量）+ VQ 量化器（→离散符号）+ Transformer（双向上下文填空）；目的 = 用海量无标注语音自学表示，省掉昂贵的语音转写标注（1 小时标注就接近之前几百小时标注的效果）
- 补充（注意：预训练 ≠ 语音辨识）：离散符号不是文字，模型从没见过"语音↔文字"的对应关系；语音辨识是下游任务——保留预训练的 encoder+Transformer，接一个"语音转文字"的头，用少量标注（语音+转写文字）微调才能转出文字

### Wav2vec 和 BERT 之间的联系

- BERT 也可以看成是一个分类问题：输出的 embedding 和正确的文字的向量更近，希望正确的字被输出的概率大
- 错误的字太多了 → 只 sample 几个不正确的字来和最后一层网络相乘，这样来训练（负采样）

## 五、没有负样本怎么办：Bootstrapping 与 BYOL

### 问题：负样本不好挑

- 错误样本需要挑选：**不能太难（学不动），也不能太简单（学不到）**
- 怎么避开样本的挑选？
- 如果没有错误样本，机器会把所有的输入都判定为接近 → **collapse（崩塌）**：所有样本都被映射到同一个向量，表示完全退化，什么都没学到

### 思路：Bootstrapping（自举）

- 让一张图片产生向量，让另一张图也产生向量，同样希望越近越好
- 但只对其中一边做梯度下降，然后把两种模型的参数进行同步
- 架构：右边比左边多一个 predictor（左边只有 encoder，右边是 encoder + predictor），其中 encoder 参数同步
- 补充（回答疑问）：
  - **predictor 的参数需要更新吗？** 需要！predictor 在被训练的那一侧，正常梯度下降；参数同步的只有两侧的 encoder
  - **predictor 的作用**：让训练侧学会"预测"另一侧的输出——两侧结构不对称，正是为了打破 collapse
  - **一开始的 encoder 从哪里来？** 从随机初始化开始，训练中逐渐学出来

### BYOL（Bootstrap Your Own Latent）

- 通过**渐进的方式**影响 encoder（EMA 指数移动平均）
- 补充公式：**θ_target ← τ·θ_target + (1−τ)·θ_online**，τ 接近 1（如 0.99~0.999）
- 含义：target 网络的参数是 online 网络参数的滑动平均——online 每次更新一点，target 慢悠悠地跟上，这就是"渐进式"影响

## 六、不用负样本、不用不对称结构：正则化方案（VICReg）

- Simply extra regularization
- **Invariance（不变性）**：让两个正样本的向量相近——和对比学习的目标一样
- **Variance（方差）**：输入一个 batch 的图片，希望输出向量的每一个维度的方差大于一定值——防止 collapse（全部相同时方差为 0，会被惩罚）
- **Covariance（协方差）**补充：希望输出向量不同维度之间相互独立（协方差接近 0）——防止维度冗余（各维度重复编码同一份信息，浪费表示能力）
