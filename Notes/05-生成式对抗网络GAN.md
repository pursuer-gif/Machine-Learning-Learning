# 机器学习听课笔记 5：生成式对抗网络 GAN

> 李宏毅课程

---

## 一、为什么需要生成模型

### 为什么输出需要是一个分布

有些任务同一个输入有多个**等可能的正确输出**。用学过的方法（输出单点）训练，机器会在多个正确选择之间"平均化"而出错——比如 video prediction：向右走是对的，向左走也是对的，但模型不能同时输出左右。

**当任务需要创造力时，就需要输出一个分布**：

- 画一个红眼睛的人（多种合理画法）
- 聊天机器人（同一句话有不同的合理回答）

思路：从简单分布 z 中 sample，经过 generator 变成复杂的分布 y。**同一个输入，按几率给出不同答案，让机器学会"不可预测"的输出。**

---

## 二、GAN 基本概念

### 组成

- **Generator（生成器）**：吃低维 z（如正态分布），生成高维输出（如图片），目标是让生成分布接近真实分布
- **Discriminator（判别器）**：吃一张图，输出一个 scalar，越大表示越像真图（如二次元头像）。架构可自己定

### 训练过程

Generator 产生例子想骗过 Discriminator，Discriminator 努力分辨真假——**互相对抗、共同进步**（写做敌人，念做朋友）。训练策略：**固定其中一个，训练另外一个**，交替迭代。

> 这是不是自监督学习？——不是。GAN 属于**无监督学习**（没有标签，靠两个网络的对抗信号驱动），自监督靠的是构造伪标签（如掩码预测）。

**应用**：Anime Face Generation（Unconditional Generation）等，还有大量变形：**ACGAN、BGAN、CGAN、DCGAN、EBGAN、fGAN**……

---

## 三、GAN 理论

### 核心目标

假设输入是一维向量，经过 Generator 后分布被映射得更复杂（pG），与理想分布（p_data）比较，计算距离并希望距离最小。**难点：分布之间的距离很难直接算。**

**方案**：sample 一些样本出来就足够好——后续通过训练 Discriminator 实现，因为 Discriminator 的目标就是对真实图和生成图做区分，**它判断"能否分开"的能力就反映了分布距离**。

### 数学形式

原始 GAN 的优化目标（min-max game）：

$$G^* = \arg\min_G \max_D V(G, D)$$

其中：

$$V(G, D) = E_{x \sim p_{data}}[\log D(x)] + E_{z \sim p_z}[\log(1 - D(G(z)))]$$

**直观理解**：
- 若 pG 和 p_data 接近 → 很难分开 → V 的值小
- 若距离大 → 容易分开 → V 的值大
- 所以 max_D V 可以作为"距离"的度量

**这个函数与 JS divergence（JS 散度）有关**：当 D 取到最优时，V 的最大值恰好等于 JS 散度的变形。

### 补充：JS Divergence 是什么

JS 散度（Jensen-Shannon Divergence）度量两个分布的重叠程度，是 KL 散度的对称版本：

$$D_{JS}(P \| Q) = \frac{1}{2}D_{KL}(P \| M) + \frac{1}{2}D_{KL}(Q \| M), \quad M = \frac{P+Q}{2}$$

- 取值 [0, log2]，对称（$D_{JS}(P\|Q) = D_{JS}(Q\|P)$），比 KL 更稳定
- GAN 的判别器本质就是一个二分类问题（真/假），最优判别器的 loss 与 JS 散度直接挂钩

## 四、GAN Tips：JS 散度的问题

**两个致命问题：**

1. **重叠区域太少**：pG 和 p_data 的相交部分可能极少甚至为 0
2. **采样稀疏**：即使两个分布本身有重叠，sample 出的点不够多时，看起来也不重合

**后果**：如果两个分布没有重叠，判别器能完美区分 → JS 散度恒为 log2，**无法判断距离远近** → 梯度消失，训练停摆。

---

## 五、Wasserstein Distance（推土机距离）

**直觉**：把 p 想象成一堆土，q 是另一堆土。Wasserstein 距离 = 把 p 这堆土**推**成 q 的最小搬运成本（土量 × 移动距离）。

**为什么比 JS 好**：
- JS 在分布不重叠时是常数（log2），梯度消失
- Wasserstein 距离**每一点变化都能体现出来**，即使分布完全不重叠，距离也在连续变化

**问题**：如果 p 和 q 形状差距大，搬运方式有很多种 → 定义取**所有方案里最短的那个**（最优运输问题）。穷举所有方案计算量太大，但理论价值远大于 JS。

---

## 六、WGAN

用 Wasserstein 距离替代 JS 散度的 GAN 变体：

$$\max_D \; E_{x \sim p_{data}}[D(x)] - E_{z \sim p_z}[D(G(z))]$$

**关键约束**：D 必须足够**光滑**（1-Lipschitz 连续），不能有太大突变——否则两堆数据没重叠时，任意几组值的差值都可能无穷大。

**仍存在的问题（实践中的近似误差）**：理论上对偶定理保证 max 值精确等于 Wasserstein 距离——分布越远差值必然越大。但实际 D 是有限参数的神经网络，只覆盖 1-Lipschitz 函数空间的一小部分；原始 WGAN 用 weight clipping 实现 Lipschitz 约束更是严重压缩表达能力，导致真实训练中"距离远但差值不大"的现象。问题不在距离定义，而在**神经网络近似最优 D 的误差**。

### 深入理解：差值与距离的真实关系

**差值 = max over 函数族 [E_P[D] − E_Q[D]]**——这个 max 是在**给定的函数族**里挑，所以：

| | 差值大小 |
|---|---|
| 距离远近 | 只决定**天花板**（对偶定理：遍历全部 1-Lipschitz 函数时差值 = 距离） |
| 函数族内容 | 决定**实际能榨出多少**（族里没有好函数 → 差值被锁死） |

- **函数族 = 所有 1-Lipschitz 函数**：包含 $f(x)=x$ 这类线性函数。P 在 0 附近、Q 在 1000 附近时，差值可达 1000，恰好等于距离。max 会选它。
- **函数族里只有周期函数**（如 sin）：$|E_P[\sin] - E_Q[\sin]| \leq 2$，差值被函数的有界性锁死——分布隔得再远也测不出来。

**所以 D 最好是单调的**：测距目标要求 D 给 P 区域最高分、Q 区域最低分、中间平滑过渡（1-Lipschitz），这自然是一个单调递增的 sigmoid 形函数。周期函数给 P 和 Q 的分值来回震荡，可能把 P 打在波谷、Q 打在波峰，差值被压缩。实际训练中 D 不强制单调，但"给真图高分、假图低分"的目标会自然把它推向单调方向。

**这也解释了 GAN 稳定性的全部历史**：
- 原始 GAN（JS 散度）：判别器等价于固定二分类损失，函数形状被锁死 → 分布不重叠时差值恒为 log2
- WGAN（理想）：D 在 1-Lipschitz 函数族里自由选 → 差值 = 距离
- WGAN 实际：神经网络函数族有限（weight clipping 后更窄）→ 可能不含"好尺子" → 差值 < 距离
- WGAN-GP / Spectral Norm：拓宽 D 能表达的函数族，让它更有机会找到那把"好尺子"

**改进方向**：
- **Improved WGAN（WGAN-GP）**：用 Gradient Penalty 强制满足 Lipschitz 约束
- **Spectral Normalization（谱归一化）**：限制每层权重矩阵的最大奇异值，保证 D 的平滑性

## 七、Summary

```
为什么生成模型：任务需要创造力，输出必须是分布
GAN：Generator 造假 + Discriminator 分辨，对抗进步
距离度量进化：
  JS Divergence → 分布不重叠时梯度消失 ✗
  Wasserstein Distance → 处处连续可导 ✓ → WGAN
  WGAN-GP / Spectral Norm → 解决 Lipschitz 约束 ✗→✓
```
