# 听课笔记10：Autoencoder 与降维（化繁为简）

## 一、Autoencoder（自编码器）

- 类似自监督学习：不需要标注资料的学习；预训练然后微调做下游任务
- 结构：输入图片 → encoder → vector → decoder → 输出图片；希望输入和输出相似
- 把高维输入转化为低维向量（low dim，bottleneck，维度下降）——从宽到窄到宽
- 为什么需要 Autoencoder：图片维度虽高，但变化可能是有限的 → 低维向量就能表示 → 只用比较少的训练资料就能学会
- **De-noising Autoencoder**：encoder 的输入是有噪声的，decoder 要尝试把噪声去掉
- BERT 相当于 encoder（输出 embedding），后面的 linear transform + softmax 部分可以看成是 decoder

## 二、化繁为简：Clustering & Dimension Reduction

### Clustering（聚类）

- 分类：有些不同的可以分到同一类；具体分几类要自己训练、调整、摸索
- **K-means**：假设分成 k 类，每类有一个中心（可从训练数据随机筛选），所有训练数据根据中心分类；迭代优化中心：$c_i = \frac{1}{|b_i|} \sum_{x \in b_i} x$（第 i 类中心 = 该类所有样本的平均）
- **层次聚类**：第一步先建一棵树，叶子结点是原始数据，把两个最接近的叶子结点平均起来当成新节点（类似哈夫曼树），直到变成根节点；然后根据树的结构决定类的分割
- 问题：每个数据只归一个类容易以偏概全（它可能还有其他不同的特征）→ **distributed representation（分布式表示）**
- 很多时候没必要那么高的维度，低维度就足够把他们分开了

### Dimension Reduction（降维）

- 输入 vector 输出 vector，只是输出的维度低

## 三、PCA（主成分分析）

### 基本思想：找投影后方差最大的方向

- $z = Wx$，主要目的是找 W：把 X 从高维投影下来（W 相当于投影面），投影较为分散好——**large variance is better**；w 的模是 1？
- $Var(z_1) = \sum(z_1 - \bar{z}_1)^2$（注意要平方，否则恒为 0）；$w_1$、$w_2$ 需要正交（不相关，成分不会重叠）
- Var 可变形为 $w_1^T Cov(x) w_1$，找一个 $w_1$ 让这个值最大
- 矩阵 S 是半正定矩阵：特征值没有负的（都 ≥ 0）
- $w_1$ 是 S 矩阵（协方差矩阵）里最大特征值 $\lambda_1$ 对应的特征向量
- 拉格朗日乘子：$g(w_1) = w_1^T S w_1 - \alpha(w_1^T w_1 - 1)$
- 再找 $w_2$：与 $w_1$ 正交，对应第二大特征向量

### PCA-decorrelation（去相关）

- 各个输出之间没有关联（正交）可以避免过拟合

### 另一种直观说明：PCA ≈ 单层线性网络（线性 autoencoder）

- 整个操作的目的：找一个低维表示 $c$（k 个数字），保留原始高维数据（如 4096 维图片）的绝大部分信息——评判标准是"重建得够不够像"：只用 k 个数字能还原原图，说明数据的主要波动就在这 k 个主方向上，其余维度只是细节/噪声
- 重建误差最小 ≡ 投影方差最大：和前面 z=Wx 的视角等价（方差大 = 信息多 = 能重建）
- 把 $x - \bar{x}$（减平均）看成输入，$w_1$、$w_2$、$w_3$ 看成权重，一个网络后得到 $c_1$，再得到 $\hat{x}_1$、$\hat{x}_2$、$\hat{x}_3$
- 编码：$c_i = w_i^T(x - \bar{x})$——x 在 $w_i$ 方向上的投影分量
- 补充（$\bar{x}$ 是什么）：$\bar{x} = \frac{1}{N}\sum_{n} x_n$——所有训练数据的平均向量（"平均图/平均脸"），即数据中心
  - 为什么编码前减 $\bar{x}$：w 是"方向"，方向必须从原点出发；数据可能整体偏在某处，先减均值把中心移到原点，w 才能描述"围绕中心的波动方向"（不减去的话，绝对位置会把主方向带偏，变成分析"离原点最远"而不是"散得最开"）
  - 为什么重建时加回：编码时减掉了，解码时加回来，否则结果整体偏移
  - 为什么不直接分析整体：绝对位置对所有样本都一样、无区分信息；x = x̄ + (x - x̄) = 公共部分 + 个体差异，主成分只描述差异，省维度
- 解码（重建）：$\hat{x} = \bar{x} + c_1w_1 + c_2w_2 + \dots$——所有成分线性组合拼回原图；$\hat{x}$ 是和 x 同维度的向量，$\hat{x}_1$、$\hat{x}_2$、$\hat{x}_3$ 是它的各个分量
- 目标：让 $\hat{x}$ 和 $x$ 越接近越好（重建误差最小）——和"$\hat{x}$ 接近 $x - \bar{x}$"等价（$\bar{x}$ 是常数）
- 为什么像一层隐藏层：编码用 W，解码用 Wᵀ（权重共享）——就是一个线性 autoencoder
- 用梯度下降和自编码器训练的方法不太相同：没有办法保证各个 w 是垂直的

### PCA 的弱点

- 可能会把原来差距大的两组特点之间的区别减弱
- PCA 是线性的：如果数据集是三维的曲面，PCA 无法把曲面拉直，可能只是压缩到一个二维平面上

### 维度问题（为什么 6 维 PCA 后最多还是 6 维）

- 计算特征向量的 ratio 可以判断后几个包含的信息不多
- 补充：PCA 本身不降维，只是旋转坐标系（w₁ 最分散 → w₆ 最不分散），维度数不变
  - 上限 = 协方差矩阵秩 ≤ 6：6 维空间最多 6 个正交方向，第 7 个必是前 6 个的线性组合（不独立）
  - 降维发生在"选择保留前 k 个"：ratio = λᵢ/Σλⱼ = 该方向的信息占比，占比小的尾巴可丢
  - 不能多加维度 = 线性变换不创造信息（信息守恒）；想增维只能引入新信息（新特征/核方法）——这正是 PCA"线性"弱点的本质
- 补充（中心化减的是自由度，不是维度）：
  - 减均值不改变向量维度：x - x̄ 算出来还是 6 维
  - 真正的约束 Σ(xₙ - x̄) = 0 是"跨样本"约束（每个维度上所有样本求和 = 0）：自由度 N → N−1——知道 N−1 个样本，第 N 个被强制确定；它**不是**"跨维度"约束——知道一个样本的前 5 个特征，推不出第 6 个特征
  - 样本很少时（N−1 < d）：非零特征值最多 N−1 个；样本充足时仍可到 d 个
  - 第 6 维是否多余，看数据本身：λ₆ ≈ 0（数据没在那个方向展开）才冗余——是数据属性，不是中心化造成

## 四、NMF 与矩阵分解

### 为什么需要 NMF

- 因为特征不一定全都是加的，还可能是减的，所以组成不一定都是图片里有的

### NMF（Non-negative Matrix Factorization，非负矩阵分解）

- 如果所有的组成部分和权重都是正的话，那么每一个主成分都会比较像是整体里本来都有的部分
- 补充：NMF = 矩阵分解 + 约束（W、H 所有元素 ≥ 0）——成分只能"加"不能"减"，所以每个成分像真实"部件"（人脸的眼睛、鼻子），可解释性好；PCA 允许负值，成分是抽象方向

### 矩阵分解与潜在因子（推荐系统的思路）

- 有些东西内在的联系不会显现出来，我们只能看到表面的一些关系
- 内在关系可以看成两个矩阵，它们相乘是外在关系的矩阵：nA1 = rA × r1，以此类推
- 假如外在关系上有一些未知的数据：根据外在联系推测内在联系，然后用完整的内在关系预测外在——一些推荐系统会使用这样的方法
- 在此基础上可能再考虑外在的固定影响，可以加上一些 bias
- 损失：Minimizing $L = \sum(r_i r_j - n_{ij})^2$
- Latent semantic analysis（LSA）、PLSA、LDA——补充：潜在语义分析，把"文档-词"矩阵分解成"文档-主题 × 主题-词"，和上面的矩阵分解是同一思想

## 五、Neighbor Embedding（邻域嵌入）

### Manifold Learning（流形学习）

- 把曲折的高维展平？
- 补充：假设高维数据躺在一个低维弯曲流形（manifold）上（局部平坦、整体弯曲，如瑞士卷、地球表面），沿着曲面把它"展开"成低维表示；展开时保持局部邻近关系

### LLE（Locally Linear Embedding，局部线性嵌入）

- 在数据中心先找一个点，然后另外找几个点，用他们线性组合构成 $x_i$ 时的权重 $w_{ij}$ 代表他们之间的关系
- $x_i - \sum w_{ij} x_j$ 最小
- 然后在保持 $w_{ij}$ 不变的情况下，找出新的数据分布，让 $z_i - \sum w_{ij} z_j$ 最小——用权重倒推数据找出来
- 需要挑选合适的邻居数量

### Laplacian Eigenmaps（拉普拉斯特征映射）

- $S = \frac{1}{2} \sum w_{ij}(z_i - z_j)^2$（平滑度？）：原本在高维距离近的，降维后距离也应该接近；s 越小越好——但如果 $z_i$、$z_j$ 都是相同的，值就只有 0 了
- 补充（"对 z 的维度展开特别的条件"）：必须对 z 加约束（如固定方差/标准化），否则"全部 z 都等于同一个数"会让 S=0，得到无意义的平凡解

### t-SNE

- 前面只假设相近的点要在一起，**没假设不相同的点要分开**（t-SNE 补上了这一点）
- 先把 x 投射到低维的 z：$p(x_j|x_i) = S(x_i, x_j) / \sum_{k \neq j} S(x_i, x_k)$（除以除了 x_j 之外所有的）
- z 也是用相同的办法处理，做一个标准化，把他们都变成几率
- 希望能找一组 $z_i$、$z_j$ 让分布之间的差值最小（越近越好）
- 补充公式（损失 = KL 散度）：$L = \sum_i \sum_j p(x_j|x_i) \log \frac{p(x_j|x_i)}{q(z_j|z_i)}$——让高维的相似度分布 p 和低维的 q 尽量一致
- 一般会先用 PCA 降到比较低，再用 t-SNE 降到更低（都降到 2 维）
  - 补充（为什么先 PCA）：t-SNE 要算所有点两两之间的相似度（O(N²)），先 PCA 降维又快又能去噪
- $s(x_i, x_j) = \exp(-\|x_i - x_j\|^2)$；SNE 和 t-SNE 是有区别的：
  - 补充：SNE 高维低维都用高斯分布；t-SNE 低维改用 **t 分布（胖尾）**——解决"拥挤问题"，让近的更近、远的更远，变成一群一群的（你理解的"小的变小、距离大的拉大"是对的）
